## 基本対策の徹底だけで、現在の攻撃速度に対応できるのか

## 1．今回の問題提起

総務省は、ウェブサイトやモバイルアプリについて、基本的な対策不足が原因とみられる情報漏えい事例が複数確認されているとして、対策の徹底を呼びかけた。

これに対するCHOIIZUKAの指摘は、基本対策を否定するものではない。

> 基本対策が必要なのは当然である。  
> しかし、問題は「過去の基本を徹底していても破られ得る時代になり、その進行も超高速になっている」という脅威認識にある。  
> 基本ができていなかった事例を確認するだけでは、その変化に対応できることの証明にはならない。

ここでいう攻撃の速度や、基本対策を実施していた個々の組織の状況については、事案ごとの検証が必要である。本記録では、上記をCHOIIZUKAの現状認識と問題提起として残す。

## 2．「不足が見つかった」と「不足が原因のすべて」は違う

議論では、次の三つを区別する必要がある。

1. 調査した事例に、基本対策の不足が見つかった。
2. その不足が、その事例の侵入・被害拡大に寄与した。
3. 基本対策を徹底すれば、現在の攻撃にも十分対応できる。

一つ目が確認されても、二つ目には原因分析が必要であり、三つ目が自動的に成立するわけではない。

CHOIIZUKAが懸念しているのは、説明が「基本ができていなかったから起きた」に収束し、基本対策を実施した後にも残る問題――攻撃の組み合わせ、対応までの時間差、侵害後の被害拡大――の検討が後景に退くことである。

ただし、政府が意図的にその説明へ誘導しているかは、今回の投稿だけでは確認できない。「そのシナリオにしたいように見える」という本人の見立てと、確認された政策意図は区別する。

## 3．政府文書に書かれた対策と、実効性の検証は別である

今回参照した11月5日の国家サイバー統括室の文書は、基本対策に加え、比較的低く評価されたリスクの組み合わせ、AIによる攻撃の高度化・効率化、管理境界の分離、緊急時の機能停止やアクセス制限などにも言及している。[1932]

したがって、「政府は新しい脅威を一切認識していない」とするのは正確ではない。

しかし、文書に対応方針があることと、実際のシステムが攻撃の速度に間に合うことは別である。今回の問題提起から導かれる検証事項は、次のとおりとなる。

- 基本対策を実施した後に、何が残存リスクとして残るのか。
- 攻撃開始から情報持ち出しまでの時間に、検知・判断・遮断が間に合うのか。
- 一つのアカウントや管理領域が侵害されたとき、どこまで到達できるのか。
- 人の承認や組織間調整を待つ間に、被害が拡大しないか。
- これらを方針の記述だけでなく、実際の試験で確認しているか。

これは「政府も事故を起こした」という批判とは異なる。対策の前提と、有効性を確かめる方法への問いである。

## 4．マイナンバーに関する懸念の正確な位置付け

CHOIIZUKAは、国民のデータを収集・管理する仕組みそのものへの懸念も示した。

技術的な整理として、マイナンバー制度は、国民のあらゆる情報を一か所の共通データベースに集める仕様ではない。公式には、各機関が情報を保有し、必要な情報を必要なときにやり取りする分散管理を採用している。[2084][2086]

そのため、本レポートでは「国が全データを一か所に集約している」とは記載しない。

一方、今回の問題意識は、単にデータの置き場所が集中しているかどうかに限定されない。行政機関が個人情報を保有・連携する仕組みにおいて、その権限、照会経路、処理、運用が侵害・誤作動したとき、被害をどこまで限定できるかという問いとして整理する。政府の検討資料にも、集中管理と分散管理の二元論ではなく、情報の扱われ方に即した実効的なリスク管理が重要との議論がある。[2088]
